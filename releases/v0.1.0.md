# PatchBoard 0.1.0

Initial versioned release of the standalone repo-native task board and annotation
linter.

- Create, inspect, move, repair, and validate Markdown task boards with the CLI.
- Use `-C` / `--repo` to select a repository. Automatic discovery stops at Git
  worktree boundaries; legacy trailing repository arguments remain supported.
- Run `patchboard` for status, use JSON output for automation, and inspect
  repository health with `doctor`.
- Open the bundled kanban board, remember its tasks folder, reconnect permissions,
  and undo the most recent browser move.
- Download Linux, macOS (`darwin`), and Windows binaries for amd64 or arm64.
  Archives include licenses; `checksums.txt` contains SHA-256 hashes.
- Inspect the installed binary's version with `patchboard --version`.

## Migration and limitations

Install the standalone binary on `PATH`; consuming projects only need their
`tasks/` tree. Existing source-submodule users can continue with an explicit
`--repo` path while migrating. The Go module is now
`gitlab.com/off-peak.engineer/utilities/patchboard`.

Browser folder access and writable drag-and-drop require File System Access API
support and permission. Other browsers display an unsupported message. Folder
persistence and app installation depend on browser capabilities. Native browser
permission flows have not yet been manually verified for this release candidate.

The release binaries are cross-compiled; macOS and Windows runtime smoke tests
remain a maintainer check. Archives are not code-signed or notarized. The GitLab
project is currently private, so downloads require project access.
