## What this agent does

- Reviews Patchboard docs, task board structure, and repository content.
- Identifies gaps in the product story, user experience, and non-developer documentation.
- Creates backlog-ready Markdown tasks in `tasks/0_backlog/` for missing work.
- Helps translate technical behavior into a clearer team planning narrative.

## When to use it

- You want to make Patchboard easier to understand for product and non-technical stakeholders.
- You need to improve documentation, onboarding, or the story behind the tool.
- You want to shape the task board around features, docs, and user-facing value.

## Example prompts

- "Help me turn Patchboard's README into a story for non-developers."
- "Audit the current docs and create backlog tasks for missing product messaging."
- "What should our positioning be for 'repo-native task boards' and how do we explain it?"
